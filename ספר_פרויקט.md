# 📘 ספר פרויקט – מערכת ניהול תורים (QueueSystem)

---

## 1️⃣ מבוא

### רקע הפרויקט

פרויקט זה הוא **מערכת ניהול תורים דיגיטלית**. המטרה היא לאפשר ללקוחות לקחת מספר בתור באופן מקוון ולעקוב אחרי מיקומם, ולאפשר למנהלים לנהל את התורים בסניפים השונים.

**קהל היעד:** שני סוגי משתמשים:
1. **לקוח (User)** – לוקח מספר בתור, עוקב אחרי מיקומו
2. **מנהל (Admin)** – מנהל סניפים, שירותים, משתמשים, וקורא לתורות

### מטרות המערכת

| מטרה | תיאור |
|---|---|
| לאפשר לקיחת תור דיגיטלית | הלקוח בוחר סניף ושירות ומקבל מספר |
| מעקב בזמן אמת | הלקוח רואה את מיקומו בתור ואת הסטטוס |
| ניהול תורים על ידי מנהל | המנהל קורא לתור הבא, מדלג, סוגר |
| ניהול מערכת | ניהול סניפים, שירותים ומשתמשים |
| יומן פעילות | רישום כל קריאות התור ב-CallLog |

### פלטפורמות המערכת

המערכת פותחה בשלוש פלטפורמות:

| פלטפורמה | טכנולוגיה | מיקום בפרויקט |
|---|---|---|
| Desktop – לקוח רגיל | WPF (C#) | `QueueClients/QueueClients` |
| Desktop – מנהל | WPF (C#) | `QueueClients/AdminClient` |
| אתר Web | ASP.NET WebForms | `WebClient/WebClient` |
| שרת הלוגיקה | WCF Service (C#) | `QueueManagement/WcfServiceLibrary1` |

## 2️⃣ ניתוח המערכת

### מצב קיים לפני המערכת

בסניפים רבים (בנקים, קופות חולים, משרדי ממשלה) קיימים מכשירי תורנות פיזיים בלבד. החסרונות:
- הלקוח חייב להיות פיזית בסניף כדי לקחת מספר
- אין מעקב בזמן אמת מרחוק
- אין ניהול מרכזי של מספר סניפים

### פתרון המערכת

מערכת דיגיטלית שמאפשרת:
- לקיחת מספר מהמחשב הביתי או הנייד
- מעקב בזמן אמת
- ניהול מרכזי ממספר סניפים

### תרשים UseCase

### ERD – קשרים בין הטבלאות

```
Users ──────────────────────────┐
  │UserId (PK)                  │ (CalledBy)
  │...                          ▼
  │              CallLog ────────────────────
  │               LogId (PK)                 │ TicketId
  │               TicketId (FK)              │
  │               CalledBy (FK → Users)      │
  │               CalledAt                   │
  │                                          │
  │              QueueTickets ◀──────────────┘
  │               TicketId (PK)
  └──────────────▶ UserId (FK → Users)
                   ServiceId (FK → Services)
                   BranchId (FK → Branches)
                   TicketNumber
                   Status
                   CreatedAt / CalledAt / CompletedAt

Services ──────────────────────────────────────────
  ServiceId (PK)                     ▲
  ServiceName                        │ ServiceId (FK)
  AvgDuration                        │
  BranchId (FK → Branches) ─────┐   │
  IsActive                      │   │
                                 ▼   │
Branches                    QueueTickets
  BranchId (PK) ◀───────────────────┘
  BranchName                  BranchId (FK)
  Address
  IsActive
```

**סוגי קשרים:**
- `Users` → `QueueTickets`: יחס 1 לרבים (לקוח יכול לקחת כמה כרטיסים לאורך זמן)
- `Branches` → `Services`: יחס 1 לרבים (לכל סניף יש מספר שירותים)
- `Branches` → `QueueTickets`: יחס 1 לרבים
- `QueueTickets` → `CallLog`: יחס 1 לרבים

### View לדוגמה – ActiveQueueView

ה-View הבא מאחד נתונים ממספר טבלאות לתצוגה אחת נוחה:

```sql
CREATE VIEW ActiveQueueView AS
SELECT 
    qt.TicketId,
    qt.TicketNumber,
    qt.Status,
    qt.CreatedAt,
    u.FirstName + ' ' + u.LastName AS CustomerName,
    s.ServiceName,
    b.BranchName
FROM QueueTickets qt
JOIN Users u ON qt.UserId = u.UserId
JOIN Services s ON qt.ServiceId = s.ServiceId
JOIN Branches b ON qt.BranchId = b.BranchId
WHERE qt.Status = 'Waiting'
```

**למה נוצר ה-View?**
במקום לכתוב JOIN מורכב בכל שאילתה, אפשר לכתוב פשוט:
```sql
SELECT * FROM ActiveQueueView WHERE BranchName = 'Tel Aviv'
```
זה מקצר קוד, מונע שגיאות, ומרכז את הלוגיקה במקום אחד.

### שכבת DAL – גישה לבסיס הנתונים

#### מחלקת הבסיס `BaseDAL`

כל מחלקות ה-DAL יורשות מ-`BaseDAL`. זוהי **מחלקת אב מופשטת** (`abstract`) שמכילה את כל הלוגיקה המשותפת של חיבור לבסיס הנתונים:

```csharp
public abstract class BaseDAL
{
    protected static string ConnectionString;

    protected BaseDAL()
    {
        string DBfileName = "Database1.mdf";
        string projectDir = Path.GetFullPath(
            Path.Combine(AppDomain.CurrentDomain.BaseDirectory, @"..\..\..\DAL\"));

        ConnectionString = "Data Source=(LocalDB)\\MSSQLLocalDB;" +
            "AttachDbFilename=" + projectDir + DBfileName +
            ";Integrated Security=True";

        EnsureDatabaseSchema(projectDir);
    }
```

**הסבר:** הבנאי מוצא אוטומטית את קובץ ה-DB בנתיב יחסי – כך שגם על מחשב אחר הקוד יעבוד בלי לשנות נתיבים.

##### שלוש מתודות ליבה:

```csharp
// לשאילתות SELECT – מחזיר טבלת נתונים
protected DataTable ExecuteSelect(string sql)

// לפקודות INSERT / UPDATE / DELETE
protected int ExecuteNonQuery(string sql)

// מחזיר ערך בודד (COUNT, MAX, SCOPE_IDENTITY וכו')
protected object ExecuteScalar(string sql)
```

כל מתודה:
1. פותחת חיבור (`conn.Open()`)
2. מבצעת את הפקודה
3. סוגרת חיבור ב-`finally` (גם אם יש שגיאה)
4. מדפיסה שגיאה ל-Console במקרה כישלון

#### ⚠️ SQL Injection – בעיה ופתרון

**בעיה קיימת בקוד** – בפונקציית Login ב-`UserDAL`:
```csharp
// ❌ מסוכן! SQL Injection
string sql = $"SELECT * FROM Users WHERE Username = '{username}' " +
             $"AND Password = '{password}' AND IsActive = 1";
```

אם תכניס כשם משתמש: `admin' OR '1'='1` – ה-SQL יהפוך ל:
```sql
SELECT * FROM Users WHERE Username = 'admin' OR '1'='1' AND IsActive = 1
```
התוצאה: כניסה ללא סיסמה! זה **פרצת אבטחה חמורה**.

**הפתרון הנכון – Parameters:**
```csharp
// ✅ בטוח – עם Parameters
SqlCommand cmd = new SqlCommand(
    "SELECT * FROM Users WHERE Username = @Username AND Password = @Password AND IsActive = 1",
    conn);
cmd.Parameters.AddWithValue("@Username", username);
cmd.Parameters.AddWithValue("@Password", password);
```

כך SQL Server מתייחס לקלט המשתמש כ**נתון** בלבד ולא כחלק מהפקודה – אי אפשר לבצע הזרקה.

#### `UserDAL` – פעולות CRUD על משתמשים

```csharp
public class UserDAL : BaseDAL
{
    // קריאת כל המשתמשים
    public List<User> GetAllUsers()
    {
        string sql = "SELECT * FROM Users";
        DataTable dt = ExecuteSelect(sql);
        List<User> list = new List<User>();
        foreach (DataRow row in dt.Rows)
            list.Add(Map(row));
        return list;
    }

    // הוספת משתמש חדש
    public void AddUser(User u)
    {
        string sql = $"INSERT INTO Users (FirstName, LastName, Username, Password, " +
                     $"Phone, Email, Role, IsActive) " +
                     $"VALUES (N'{u.FirstName}', N'{u.LastName}', '{u.Username}', " +
                     $"'{u.Password}', '{u.Phone}', '{u.Email}', '{u.Role}', 1)";
        ExecuteNonQuery(sql);
    }

    // פונקציית Map – הופכת שורת DB למחלקה
    private User Map(DataRow row)
    {
        return new User
        {
            UserId = (int)row["UserId"],
            FirstName = row["FirstName"].ToString(),
            LastName = row["LastName"].ToString(),
            Username = row["Username"].ToString(),
            Password = row["Password"].ToString(),
            Phone = row["Phone"].ToString(),
            Email = row["Email"].ToString(),
            Role = row["Role"].ToString(),
            IsActive = (bool)row["IsActive"],
            CreatedAt = (DateTime)row["CreatedAt"]
        };
    }
}
```

**הסבר פונקציית Map:** מקבלת `DataRow` (שורה מהטבלה) ומחזירה אובייקט `User`. כך אפשר לעבוד עם אובייקטים C# נוחים במקום טבלאות גולמיות.

#### `QueueTicketDAL` – ניהול כרטיסי תור

פונקציה מעניינת – חישוב מספר התור הבא:
```csharp
public int GetNextTicketNumber(int branchId, int serviceId)
{
    string sql = $"SELECT ISNULL(MAX(TicketNumber), 0) + 1 FROM QueueTickets " +
                 $"WHERE BranchId = {branchId} AND ServiceId = {serviceId}";
    return (int)ExecuteScalar(sql);
}
```
**הסבר:** `ISNULL(MAX(...), 0)` – אם אין כרטיסים בכלל, `MAX` מחזיר NULL, ואז `ISNULL` מחזיר 0. ואז +1 = מספר 1. כך המספרים תמיד עולים בסדר.

עדכון סטטוס תור עם זמנים אוטומטיים:
```csharp
public void UpdateStatus(int ticketId, string status)
{
    string calledAt = (status == "Called") ? $", CalledAt = GETDATE()" : "";
    string completedAt = (status == "Done" || status == "Skipped")
                          ? $", CompletedAt = GETDATE()" : "";
    string sql = $"UPDATE QueueTickets SET Status = '{status}'{calledAt}{completedAt} " +
                 $"WHERE TicketId = {ticketId}";
    ExecuteNonQuery(sql);
}
```
**הסבר:** בהתאם לסטטוס החדש, SQL מוסיף אוטומטית את זמן הקריאה או סיום השירות (`GETDATE()` = זמן נוכחי בשרת).

### שכבת BLL – לוגיקה עסקית

#### `QueueTicketBLL` – לב המערכת

פונקציית `TakeTicket` – כאן קורה הלוגיקה המרכזית:
```csharp
public QueueTicket TakeTicket(int userId, int serviceId, int branchId)
{
    // 1. בדיקה שהמשתמש לא כבר בתור
    QueueTicket existing = _dal.GetActiveTicketByUser(userId);
    if (existing != null)
        throw new Exception("You already have an active ticket");

    // 2. מחשב מספר תור הבא
    int ticketNumber = _dal.GetNextTicketNumber(branchId, serviceId);

    // 3. יוצר כרטיס תור חדש
    QueueTicket ticket = new QueueTicket
    {
        TicketNumber = ticketNumber,
        UserId = userId,
        ServiceId = serviceId,
        BranchId = branchId,
        Status = "Waiting"
    };

    // 4. שומר ב-DB ומקבל TicketId
    ticket.TicketId = _dal.AddTicket(ticket);
    return ticket;
}
```

פונקציית `GetPositionInQueue` – מחשב מיקום בתור:
```csharp
public int GetPositionInQueue(int ticketId, int branchId, int serviceId)
{
    List<QueueTicket> waiting = _dal.GetWaitingTickets(branchId, serviceId);
    for (int i = 0; i < waiting.Count; i++)
    {
        if (waiting[i].TicketId == ticketId)
            return i + 1;  // +1 כי הספירה מ-0
    }
    return 0;  // לא נמצא
}
```

פונקציית `CallNextTicket` – קריאה לתור הבא + רישום ביומן:
```csharp
public void CallNextTicket(int branchId, int serviceId, int adminId, string notes = "")
{
    List<QueueTicket> waiting = _dal.GetWaitingTickets(branchId, serviceId);
    if (waiting.Count == 0)
        throw new Exception("No waiting tickets");

    QueueTicket next = waiting[0];  // הראשון בתור
    _dal.UpdateStatus(next.TicketId, "Called");

    // רישום ב-CallLog
    CallLogDAL logDal = new CallLogDAL();
    logDal.AddLog(new CallLog
    {
        TicketId = next.TicketId,
        CalledBy = adminId,
        Notes = notes
    });
}
```

#### `UserBLL` – ולידציות לוגיקה עסקית

```csharp
public void Register(User u)
{
    // ולידציה: שדות חובה
    if (string.IsNullOrWhiteSpace(u.FirstName) || string.IsNullOrWhiteSpace(u.LastName))
        throw new Exception("First and last name are required");
    if (string.IsNullOrWhiteSpace(u.Username))
        throw new Exception("Username is required");
    if (string.IsNullOrWhiteSpace(u.Password))
        throw new Exception("Password is required");

    // ולידציה: ייחודיות
    if (_dal.UsernameExists(u.Username))
        throw new Exception("Username already exists");
    if (_dal.IsPhoneExists(u.Phone))
        throw new Exception("A user with this phone number already exists!");

    u.Role = "User";  // תמיד לקוח רגיל בהרשמה
    _dal.AddUser(u);
```

### שכבת WCF – שרת השירות

#### ממשק `IService1`

```csharp
[ServiceContract]
public interface IService1
{
    // כניסה והרשמה
    [OperationContract] User Login(string username, string password);
    [OperationContract] void Register(User u);

    // סניפים
    [OperationContract] List<Branch> GetAllBranches();
    [OperationContract] void AddBranch(Branch b);
    [OperationContract] void UpdateBranch(Branch b);
    [OperationContract] void DeleteBranch(int branchId);

    // שירותים
    [OperationContract] List<Service> GetAllServices();
    [OperationContract] List<Service> GetServicesByBranch(int branchId);
    [OperationContract] void AddService(Service s);
    [OperationContract] void UpdateService(Service s);
    [OperationContract] void DeleteService(int serviceId);

    // משתמשים
    [OperationContract] List<User> GetAllUsers();
    [OperationContract] User GetUserById(int userId);
    [OperationContract] void AddUser(User u);
    [OperationContract] void UpdateUser(User u);
    [OperationContract] void DeleteUser(int userId);

    // תורות
    [OperationContract] QueueTicket TakeTicket(int userId, int serviceId, int branchId);
    [OperationContract] QueueTicket GetActiveTicketByUser(int userId);
    [OperationContract] List<QueueTicket> GetTicketsByBranch(int branchId);
    [OperationContract] List<QueueTicket> GetWaitingTickets(int branchId, int serviceId);
    [OperationContract] int GetPositionInQueue(int ticketId, int branchId, int serviceId);
    [OperationContract] void CallNextTicket(int branchId, int serviceId, int adminId);
    [OperationContract] void SkipTicket(int ticketId, int adminId);
    [OperationContract] void CloseTicket(int ticketId, int adminId);

    // יומן
    [OperationContract] List<CallLog> GetAllLogs();
}
```

**הסבר:** `[ServiceContract]` אומר ל-WCF שזהו ממשק שירות. `[OperationContract]` מסמן כל מתודה שחשופה ללקוחות ברשת.

#### הגדרות הרשת (`App.config`)

```xml
<endpoint address=""
          binding="basicHttpBinding"
          contract="WcfServiceLibrary1.IService1">
  <identity>
    <dns value="localhost"/>
  </identity>
</endpoint>
<add baseAddress="http://localhost:8733/.../Service1/" />
```

**הסבר:**
- **`basicHttpBinding`** – פרוטוקול HTTP רגיל, עובד עם כל לקוח (גם אתר Web)
- **`localhost:8733`** – הכתובת שבה השרת מאזין
- הלקוחות מתחברים לכתובת הזו ומקבלים גישה לכל המתודות

## 9️⃣ מדריך למשתמש

### הפעלת המערכת

**סדר ההפעלה חשוב!**

1. **הפעל קודם את ה-HOST** (פרויקט `HOST` ב-`QueueManagement`) – זה השרת שמאזין על פורט 8733
2. **אחר כך הפעל את הלקוח** (`QueueClients` או `WebClient`)

**אם תפעיל הלקוח לפני השרת** – תקבל שגיאת חיבור.

### מדריך ללקוח רגיל

| שלב | פעולה |
|---|---|
| 1 | פתח את האפליקציה / אתר |
| 2 | לחץ "Register" ומלא שם, שם משתמש, סיסמה |
| 3 | היכנס עם שם משתמש וסיסמה |
| 4 | לחץ "Take Ticket", בחר סניף ושירות, לחץ "Take" |
| 5 | עבור ל-"My Ticket" ועקוב אחרי מיקומך |
| 6 | לחץ "Refresh" לעדכון מצב |

### מדריך למנהל (Admin)

| שלב | פעולה |
|---|---|
| 1 | היכנס עם חשבון Admin |
| 2 | בחר סניף ושירות בתפריט הנפתח |
| 3 | לחץ "Call Next" לקרוא לתור הבא |
| 4 | בחר כרטיס ולחץ "Skip" לדלג |
| 5 | בחר כרטיס ולחץ "Close" לסיים שירות |

### הודעות שגיאה נפוצות

| שגיאה | סיבה | פתרון |
|---|---|---|
| "You already have an active ticket" | כבר יש לך תור פעיל | סיים/בטל את התור הקיים |
| "Username already exists" | שם המשתמש תפוס | בחר שם משתמש אחר |
| "No waiting tickets" | התור ריק | המתן שלקוחות יצטרפו |
| שגיאת חיבור | השרת לא פועל | הפעל את ה-HOST |
